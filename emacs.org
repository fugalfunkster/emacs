* Chant — Multi-Agent Claude Dashboard

Chant is a workflow layer for controlling one or more Claude Code sessions from
Emacs. It composes three things:

- *Emacs* — composition buffer, dashboard, abeyance passthrough
- *tmux* — persistent terminal session bridging Emacs (Lisp) to Claude CLI (TTY)

The canonical usage pattern:

1. Run =chant= in a terminal → creates (or attaches to) a tmux session named =claude=
2. Run =chant= in Eshell → opens the dashboard + composition split
3. Press =n= in the dashboard → spawns a named agent pair (tmux window + Claude session)
4. Write a prompt in =*chant*= → =C-c C-c= sends it to the active agent
5. Press =M-a= (abeyance) to forward keystrokes for TUI prompts without leaving Emacs
