#+TITLE: Emacs Key Bindings Reference
#+AUTHOR: Matthew Hoselton

* Config

| Binding   | Command                           | Description                          |
|-----------+-----------------------------------+--------------------------------------|
| =M-x tangle-and-restart= | — | Tangle =emacs.org= and restart Emacs |
| =M-x keyfreq-show=       | — | Show top command usage               |

* Navigation

| Binding     | Command                              | Description                       |
|-------------+--------------------------------------+-----------------------------------|
| =C-d=       | =mh/xref-toggle-definitions=        | Jump to definition / jump back    |
| =M-.=       | =mh/xref-toggle-definitions=        | Jump to definition / jump back    |
| =C-c C-.=   | =mh/xref-find-definitions-buffer=   | Show xref results in buffer       |
| =C-c i=     | =mh/eldoc-toggle-buffer=            | Toggle documentation buffer       |
| =C-s=       | =avy-goto-char-timer=               | Jump to character                 |
| =C-x C-b=   | =ibuffer=                           | Buffer list                       |
| =M-x=       | =smex=                              | Enhanced command palette          |
| =C-M-s=     | =isearch-forward=                   | Forward search                    |
| =C-M-r=     | =isearch-backward=                  | Backward search                   |
| =C-r f=     | =isearch-forward-regexp=            | Forward regex search              |
| =C-r b=     | =isearch-backward-regexp=           | Backward regex search             |

* Editing

| Binding       | Command                    | Description                    |
|---------------+----------------------------+--------------------------------|
| =M-/=         | =hippie-expand=            | Text autocompletion            |
| =C-;=         | =toggle-comment-on-line=   | Comment / uncomment line       |
| =C-a=         | =back-to-indentation=      | Move to first non-whitespace   |
| =M-k=         | =delete-whole-line=        | Delete line (no kill ring)     |
| =C-k=         | =kill-whole-line=          | Kill whole line                |
| =<M-DEL>=     | =backward-delete-word=     | Delete word backwards          |
| =C-c m c=     | =mc/edit-lines=            | Multiple cursors on lines      |
| =C-.=         | =mc/mark-next-like-this=   | Mark next occurrence           |
| =C-,=         | =mc/unmark-next-like-this= | Unmark next occurrence         |
| =C-==         | =er/expand-region=         | Expand selection               |

* Windows

| Binding   | Command       | Description               |
|-----------+---------------+---------------------------|
| =C-x o=   | =ace-window=  | Jump to window by letter  |

* Org-mode

| Binding     | Command | Description                          |
|-------------+---------+--------------------------------------|
| =C-c C-c=   | —       | Re-align table / execute at point    |
| =TAB=       | —       | Advance to next cell, re-align table |

* Web / JS / TS

| Binding | Command                    | Description        |
|---------+----------------------------+--------------------|
| =C-c w= | =web-mode=                 | Switch to web-mode |
| =C-c d= | =xref-find-definitions=    | Jump to definition |
| =C-c b= | =xref-pop-marker-stack=    | Jump back (global; TS overrides) |
| =C-c j= | =js2-mode=                 | Switch to js2-mode |

* Chant / Bebop

| Binding   | Command                         | Description                              |
|-----------+---------------------------------+------------------------------------------|
| =M-a=     | =abeyance=                      | Toggle chant passthrough mode            |
| =C-c C-c= | =claude-chant-send-buffer=      | Send buffer to active chant pane         |
| =C-c C-p= | =bebop-cue-to-active=           | Cue subtree to active Bebop session      |
| =C-c C-P= | =bebop-cue-to-session=          | Cue subtree to selected Bebop session    |
| =C-c C-j= | =bebop-jam-to-active=           | Jam subtree to active Bebop session      |
| =C-c C-J= | =bebop-jam-to-session=          | Jam subtree to selected Bebop session    |
